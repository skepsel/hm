Описание
Проект "Фильтрация и сортировка данных о банковских операциях" представляет собой решение для обработки и анализа данных о банковских транзакциях. Он включает две основные функции для фильтрации и сортировки транзакций, что позволяет пользователю легко управлять и анализировать банковские операции.

Функции
1. filter_by_state
Эта функция принимает список транзакций (в виде словарей) и параметр state, по которому выполняется фильтрация.

Функция возвращает новый список, включающий только те транзакции, у которых значение ключа 'state' совпадает с переданным в функцию значением.
По умолчанию параметр state имеет значение 'EXECUTED'.
Пример использования:

filtered_transactions = filter_by_state(transactions, state='PENDING')
2. sort_by_state
Эта функция сортирует список банковских транзакций по дате.

Функция принимает список транзакций и параметр, определяющий порядок сортировки (ascending).
Сортировка по умолчанию выполняется по возрастанию.
Пример использования:

sorted_transactions = sort_by_state(transactions, ascending=True)
3. Тестирование масок (masks)
Функция для тестирования корректности масок (например, валидации форматов данных, таких как номера карт, даты и т. д.).

4. Тестирование виджетов (widget)
Функция для тестирования интерфейса и взаимодействия с пользовательскими элементами управления.

5. Тестирование обработки (processing)
Функция для тестирования обработки и манипуляций с данными, таких как фильтрация, сортировка и другие операции, связанные с анализом транзакций.

Использование
Откройте приложение в вашем веб-браузере.
Создайте новый проект и добавьте задачи для обработки данных о банковских транзакциях.
Установите фильтры и сортировку для данных, чтобы эффективно организовать и проанализировать операции.
Используйте тестирование для проверки правильности обработки данных и взаимодействия с виджетами.
